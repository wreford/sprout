One structure for records and lists

Both languages have one structure for everything. A Sprout cell holds named fields and numbered parts, as a Lua table does, and lists count from 1 in both.

Sprout
hero : [name : "Ada", items : ["map", "lamp", "rope"]]
hero name print
hero items @ 2 print
hero items length print
prints
Ada
lamp
3
Lua
local hero = {name = "Ada", items = {"map", "lamp", "rope"}}
print(hero.name)
print(hero.items[2])
print(#hero.items)
prints
Ada
lamp
3

The string library

Lua's string library is short and sharp. Sprout's words are named for what they do, so trimming and splitting don't need a pattern. Both count positions from 1, and negative ones from the end.

Sprout
line : "  Sprout, Lua, Rebol  "
line trim print
line trim split ", " join " | " print
"ab" repeat 3 print
"hello" slice [2, -2] print
"hello" upper print
prints
Sprout, Lua, Rebol
Sprout | Lua | Rebol
ababab
ell
HELLO
Lua
local line = "  Sprout, Lua, Rebol  "
local trimmed = line:match("^%s*(.-)%s*$")
print(trimmed)
local parts = {}
for part in trimmed:gmatch("[^,]+") do parts[#parts + 1] = part:match("^%s*(.-)%s*$") end
print(table.concat(parts, " | "))
print(("ab"):rep(3))
print(("hello"):sub(2, -2))
print(("hello"):upper())
prints
Sprout, Lua, Rebol
Sprout | Lua | Rebol
ababab
ell
HELLO

Finding things in text

Lua patterns are a tiny language inside strings: %d for a digit, %- for a dash. Sprout's rules are ordinary values (decision 103), so they can be named, put in lists and built by other code.

Sprout
text : "call 555-1234 or 555-9876 today"
text find-all [repeat [3, digit], "-", repeat [4, digit]] join ", " print
prints
555-1234, 555-9876
Lua
local text = "call 555-1234 or 555-9876 today"
local found = {}
for number in text:gmatch("%d%d%d%-%d%d%d%d") do found[#found + 1] = number end
print(table.concat(found, ", "))
prints
555-1234, 555-9876

Replacing with a function

Both replace each match with what a function makes of it. Lua's gsub also gives back a count, which is why its call needs the extra brackets.

Sprout
"3 apples and 12 pears" replace-all [some digit, [n | n number * 2]] print
prints
6 apples and 24 pears
Lua
print((("3 apples and 12 pears"):gsub("%d+", function(n) return tonumber(n) * 2 end)))
prints
6 apples and 24 pears

A grammar, not just a pattern

Lua patterns can't say "this or that", and can't nest. So nested brackets mean writing a parser by hand. A Sprout rule can hold itself, so the grammar is four lines and reads like a grammar.

Sprout
expr : [
  factor : one-of [some digit, ["(", expr, ")"]]
  term : [factor, maybe-some [one-of "*/", factor]]
  term, maybe-some [one-of "+-", term]
]
["2*(3+4)", "2*(3+4", "1+2*3-4/5"] collect [t | t parse expr] print
prints
[true, false, true]
Lua
-- Lua patterns have no alternation and no recursion, so a grammar is a hand-written parser
local function parse(s)
  local pos = 1
  local expr
  local function factor()
    if s:sub(pos, pos) == "(" then
      pos = pos + 1
      if not expr() or s:sub(pos, pos) ~= ")" then return false end
      pos = pos + 1
      return true
    end
    local from, to = s:find("^%d+", pos)
    if not from then return false end
    pos = to + 1
    return true
  end
  local function term()
    if not factor() then return false end
    while s:sub(pos, pos):match("[*/]") do pos = pos + 1; if not factor() then return false end end
    return true
  end
  expr = function()
    if not term() then return false end
    while s:sub(pos, pos):match("[+-]") do pos = pos + 1; if not term() then return false end end
    return true
  end
  return expr() and pos == #s + 1
end
local results = {}
for _, t in ipairs({"2*(3+4)", "2*(3+4", "1+2*3-4/5"}) do results[#results + 1] = tostring(parse(t)) end
print("[" .. table.concat(results, ", ") .. "]")
prints
[true, false, true]

Coroutines

A generator in both. Sprout's script yields the same way a Lua coroutine does (decision 104).

Sprout
squares : script [| go : [n | yield (n * n), go (n + 1)], go 1]
squares take 5 join ", " print
prints
1, 4, 9, 16, 25
Lua
local squares = coroutine.wrap(function()
  local n = 1
  while true do coroutine.yield(n * n); n = n + 1 end
end)
local out = {}
for i = 1, 5 do out[i] = squares() end
print(table.concat(out, ", "))
prints
1, 4, 9, 16, 25

A coroutine you can go back to

This is where they part. A Lua coroutine is one live object: resuming it moves it on for everyone. A Sprout script is a value: resuming gives a new one and leaves the old one as it was. That is why a game can keep a script in its state and still rewind time.

Sprout
counter : script [| yield 1, yield 2, yield 3]
first : counter next
second : first next
second value print
-- first hasn't changed, so it can be resumed again
first next value print
prints
2
2
Lua
local counter = coroutine.create(function()
  coroutine.yield(1); coroutine.yield(2); coroutine.yield(3)
end)
coroutine.resume(counter)
local _, second = coroutine.resume(counter)
print(second)
-- there is only one counter, and it has moved on
local _, again = coroutine.resume(counter)
print(again)
prints
2
3

Your own operators

A Lua metatable gives a table its own +. In Sprout a record has a field named +, and left is the record it was sent to.

Sprout
vector : [
  + : [right | left with [x : left x + (right x), y : left y + (right y)]]
]
sum : (vector with [x : 1, y : 2]) + (vector with [x : 3, y : 4])
"[sum x], [sum y]" print
prints
4, 6
Lua
local Vector = {}
Vector.__index = Vector
function Vector.new(x, y) return setmetatable({x = x, y = y}, Vector) end
Vector.__add = function(a, b) return Vector.new(a.x + b.x, a.y + b.y) end
local sum = Vector.new(1, 2) + Vector.new(3, 4)
print(sum.x .. ", " .. sum.y)
prints
4, 6

Dates

Lua has no dates, only seconds since 1970 and os.date. In Sprout a date is a value with its own maths (decision 100).

Sprout
2026-11-20 + 30 print
2026-11-20 weekday print
prints
2026-12-20
Friday
Lua
local t = os.time({year = 2026, month = 11, day = 20, hour = 12}) + 30 * 86400
print(os.date("!%Y-%m-%d", t))
print(os.date("!%A", os.time({year = 2026, month = 11, day = 20, hour = 12})))
prints
2026-12-20
Friday

Money

Lua's numbers are floats, so 0.10 + 0.20 isn't 0.30, and $100 shared three ways loses a cent. Sprout's money is whole cents, and split hands out every one.

Sprout
$0.10 + $0.20 = $0.30 print
$19.99 * 3 print
$100.00 split 3 print
prints
true
$59.97
[$33.34, $33.33, $33.33]
Lua
print(0.10 + 0.20 == 0.30)
print(string.format("$%.2f", 19.99 * 3))
local share = 100 / 3
print(string.format("$%.2f, $%.2f, $%.2f", share, share, share))
prints
false
$59.97
$33.33, $33.33, $33.33

Unpacking

Lua's multiple assignment unpacks values one by one. Sprout's patterns unpack lists, records and pairs, with ..rest for what's left (decision 101).

Sprout
[x, y] : 640x480
x * y print
[first, ..rest] : [1, 2, 3, 4]
rest print
prints
307200
[2, 3, 4]
Lua
local x, y = 640, 480
print(x * y)
local list = {1, 2, 3, 4}
local first, rest = list[1], {table.unpack(list, 2)}
print("[" .. table.concat(rest, ", ") .. "]")
prints
307200
[2, 3, 4]

A million random trials

Both estimate pi from a million random points. On this machine Sprout took 18 ms (Node, WebAssembly SIMD) and Lua 5.4 took 67 ms. Counting a million numbers took Sprout 4.3 ms and Lua 9.5 ms. LuaJIT, where it runs, would be faster than Lua 5.4; it wasn't measured here. Sprout's draws come from a seeded hash, so its answer is the same on every run.

Sprout
hit : [n | x : noise [n, 1], y : noise [n, 2], x * x + (y * y) < 1 [1] else [0]]
range 1000000 spork hit fold [0, [total h | total + h]] * 4 / 1000000 print
prints
3.141792
Lua
local hits = 0
for i = 1, 1000000 do
  local x, y = math.random(), math.random()
  if x * x + y * y < 1 then hits = hits + 1 end
end
print(hits * 4 / 1000000)
prints
3.14156

Lua was run as Lua 5.4 through lupa, and Sprout in Node. Times are the best of several runs on one machine. Run the benchmarks to see Sprout's numbers on your own device.
