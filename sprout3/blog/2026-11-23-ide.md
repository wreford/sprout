# Greenhouse, an experimental IDE

[Greenhouse](/sprout3/ide.html) runs your program beside its code: drag a number and the game answers as you drag, see every name's live value at the end of its line, and ask any value what it understands. Pause, scrub back in time, change the code there, and the future replays as amber ghosts; or fork a what-if and watch the old code and the new run side by side.
