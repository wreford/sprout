Python is the language most people learn first. Every pair was run in Sprout 3 and Python 3.13, and the output under each one is what it actually printed.

Printing

In Sprout the message comes after the value: "hello, world" print sends print to the text. Every line reads the same way, from the thing to what happens to it.

Sprout
"hello, world" print
prints
hello, world
Python
print("hello, world")
prints
hello, world

Names for values

A colon gives a value a name. Names can have hyphens in them, like star-count, because minus always has spaces round it.

Sprout
price : 12
count : 3
price * count print
prints
36
Python
price = 12
count = 3
print(price * count)
prints
36

Left to right, always

Sprout has no precedence table. Math runs strictly left to right, so 2 + 3 * 4 is 20. Use brackets when you want something done first. There is nothing to remember.

Sprout
2 + 3 * 4 print
2 + (3 * 4) print
prints
20
14
Python
print((2 + 3) * 4)
print(2 + 3 * 4)
prints
20
14

Functions are cells

A function is a cell: inputs, a bar, then the body. The last value in the body is the answer, so there is no return. To call it, write the value after its name.

Sprout
double : [n | n * 2]
double 21 print
prints
42
Python
def double(n):
    return n * 2

print(double(21))
prints
42

Several inputs, and defaults

Every call takes one value. Several inputs go in as a list, in order, or as a record, by name. A default comes after a colon, the same way a name gets a value.

Sprout
area : [w h : 1 | w * h]
area [3, 4] print
area [5] print
area [h : 2, w : 6] print
prints
12
5
12
Python
def area(w, h=1):
    return w * h

print(area(3, 4))
print(area(5))
print(area(h=2, w=6))
prints
12
5
12

Choosing

There is no if keyword. A true or false value takes a cell to run when true, and else (an ordinary library cell) takes the other one. The whole thing is a value, like Python's conditional expression.

Sprout
size : [n | n > 100 ["big"] else ["small"]]
size 250 print
size 7 print
prints
big
small
Python
def size(n):
    return "big" if n > 100 else "small"

print(size(250))
print(size(7))
prints
big
small

Lists

collect, keep and fold are methods on the list, so a chain of them reads left to right. Python spreads the same work over comprehensions and built-in functions.

Sprout

xs sort print

[1, 1, 3, 4, 5, 9]
Python

print(sorted(xs))

Records, never changed in place

A record is a list of named fields. with makes a new record with some fields changed; the old one is never touched. Nothing in Sprout changes in place, which is why a game's state can be saved, rewound or compared at any time.

Sprout
point : [x : 1, y : 2]
point x print
moved : point with [x : 5]
moved print
point print
prints
1
[x : 5, y : 2]
[x : 1, y : 2]
Python
point = {"x": 1, "y": 2}
print(point["x"])
moved = {**point, "x": 5}
print(moved)
print(point)
prints
1
{'x': 5, 'y': 2}
{'x': 1, 'y': 2}

Text with values in it

Square brackets inside text hold a value, the same as Python's f-strings with braces. Any expression works inside them.

Sprout
name : "Ada"
"hello, [name]! you have [3 * 4] messages" print
prints
hello, Ada! you have 12 messages
Python
name = "Ada"
print(f"hello, {name}! you have {3 * 4} messages")
prints
hello, Ada! you have 12 messages

A field that may not be there

Asking for a field that isn't there is a quiet miss, not a crash, and else catches it. Python needs .get or a try for the same thing.

Sprout
user : [name : "Ada"]
user nickname else "none" print
prints
none
Python
user = {"name": "Ada"}
print(user.get("nickname", "none"))
prints
none

Matching

match is a library cell, not syntax: a value and a flat list of pattern and answer pairs. any matches anything.

Sprout
answer : [key | match [key, ["tap", "tapped", "drag", "dragged", any, "other"]]]
answer "tap" print
answer "swipe" print
prints
tapped
other
Python
def answer(key):
    match key:
        case "tap": return "tapped"
        case "drag": return "dragged"
        case _: return "other"

print(answer("tap"))
print(answer("swipe"))
prints
tapped
other

Chains of steps

Because methods go after the value, a pipeline reads in the order it runs. Python's comprehension puts the result first and the source in the middle.

Sprout
people : [[name : "Ada", age : 36], [name : "Alan", age : 41], [name : "Grace", age : 85]]
people keep [p | p age > 40] collect [p | p name] print
prints
[Alan, Grace]
Python
people = [{"name": "Ada", "age": 36}, {"name": "Alan", "age": 41}, {"name": "Grace", "age": 85}]
print([p["name"] for p in people if p["age"] > 40])
prints
['Alan', 'Grace']

FizzBuzz

cond takes pairs of test and answer and gives the first answer whose test is true. Lists in Sprout count from 1, so range 15 is 1 to 15.

Sprout
range 15 collect [n | cond [n % 15 = 0, "FizzBuzz", n % 3 = 0, "Fizz", n % 5 = 0, "Buzz", any, n]] print
prints
[1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz]
Python
print(["FizzBuzz" if n % 15 == 0 else "Fizz" if n % 3 == 0 else "Buzz" if n % 5 == 0 else n
       for n in range(1, 16)])
prints
[1, 2, 'Fizz', 4, 'Buzz', 'Fizz', 7, 8, 'Fizz', 'Buzz', 11, 'Fizz', 13, 14, 'FizzBuzz']

Recursion

A cell can call itself by name. The brackets round n - 1 matter: without them, left to right would read fib n - 1 as (fib n) - 1.

Sprout
fib : [n | n < 2 [n] else [fib (n - 1) + (fib (n - 2))]]
fib 20 print
prints
6765
Python
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(20))
prints
6765

A million random trials

This is where the two part ways. noise [n, 1] is a seeded hash, not a random number generator, so run n always draws the same numbers and the answer is the same every time. Because hit is one pure cell, spork compiles it ahead into a kernel of number math and runs it on WebAssembly SIMD or the GPU. In this test, Sprout took 19 ms in Node against 200 ms for the plain CPython loop. NumPy would close most of that gap, at the cost of rewriting the loop as array operations.

Sprout
-- estimate pi: the share of random points in the square that land inside the circle
hit : [n | x : noise [n, 1], y : noise [n, 2], x * x + (y * y) < 1 [1] else [0]]
range 1000000 spork hit fold [0, [total h | total + h]] * 4 / 1000000 print
prints
3.141792
Python
import random

hits = sum(1 for _ in range(1_000_000)
           if random.random() ** 2 + random.random() ** 2 < 1)
print(hits * 4 / 1_000_000)
prints
3.137976

A grammar

Rebol words are looked up when the rule runs, so rules can refer to each other in any order. Sprout names are bound before use (decision 25), so the grammar is one cell that names itself, with its pieces as fields.

Sprout
expr : [
  factor : one-of [some digit, ["(", expr, ")"]]
  term : [factor, maybe-some [one-of "*/", factor]]
  term, maybe-some [one-of "+-", term]
]
["2*(3+4)", "2*(3+4", "1+2*3-4/5"] collect [t | t parse expr] print
prints
[true, false, true]
Rebol
digit: charset "0123456789"
expr: [term any [["+" | "-"] term]]
term: [factor any [["*" | "/"] factor]]
factor: [some digit | "(" expr ")"]
probe collect [foreach t ["2*(3+4)" "2*(3+4" "1+2*3-4/5"] [keep parse t expr]]
Rebol isn't installed here, so this side wasn't run.

A pipeline of steps

Clojure needs the ->> macro to write steps in the order they run. In Sprout every method already reads left to right, so a pipeline is just a line.

220

The same words, the same counts. Sprout prints a record, Clojure a map.

Grouping

group-by in both. Sprout's keys are the text of each value, since a record's field names are words.

Sprout
people : [[name : "Ada", age : 36], [name : "Alan", age : 41], [name : "Grace", age : 85]]

A little language

The same little turtle language, as quoted data walked by a fold. Sprout's 'move and Clojure's 'move are both symbols you can compare.

Sprout

  match [command, ['move, state with [x : state x + amount], 'turn, state with [heading : state heading + amount], any, state]]

{:x 15, :heading 90}

for number in text:gmatch("%d%d%d%-%d%d%d%d") do found[#found + 1] = number end
print(table.concat(found, ", "))
prints
555-1234, 555-9876

Replacing with a function

Both replace each match with what a function makes of it. Lua's gsub also gives back a count, which is why its call needs the extra brackets.

Sprout
"3 apples and 12 pears" replace-all [some digit, [n | n number * 2]] print
prints
6 apples and 24 pears
Lua
print((("3 apples and 12 pears"):gsub("%d+", function(n) return tonumber(n) * 2 end)))
prints
6 apples and 24 pears

A grammar, not just a pattern

Lua patterns can't say "this or that", and can't nest. So nested brackets mean writing a parser by hand. A Sprout rule can hold itself, so the grammar is four lines and reads like a grammar.

Sprout
expr : [
  factor : one-of [some digit, ["(", expr, ")"]]
  term : [factor, maybe-some [one-of "*/", factor]]
  term, maybe-some [one-of "+-", term]
]
["2*(3+4)", "2*(3+4", "1+2*3-4/5"] collect [t | t parse expr] print
prints
[true, false, true]
Lua
-- Lua patterns have no alternation and no recursion, so a grammar is a hand-written parser
local function parse(s)
  local pos = 1
  local expr
  local function factor()
    if s:sub(pos, pos) == "(" then
      pos = pos + 1
      if not expr() or s:sub(pos, pos) ~= ")" then return false end
      pos = pos + 1
      return true
    end
    local from, to = s:find("^%d+", pos)
    if not from then return false end
    pos = to + 1
    return true
  end
  local function term()
    if not factor() then return false end
    while s:sub(pos, pos):match("[*/]") do pos = pos + 1; if not factor() then return false end end
    return true
  end
  expr = function()
    if not term() then return false end
    while s:sub(pos, pos):match("[+-]") do pos = pos + 1; if not term() then return false end end
    return true
  end
  return expr() and pos == #s + 1
end
local results = {}
for _, t in ipairs({"2*(3+4)", "2*(3+4", "1+2*3-4/5"}) do results[#results + 1] = tostring(parse(t)) end
print("[" .. table.concat(results, ", ") .. "]")
prints
[true, false, true]

Coroutines

A generator in both. Sprout's script yields the same way a Lua coroutine does (decision 104).

Sprout
squares : script [| go : [n | yield (n * n), go (n + 1)], go 1]
squares take 5 join ", " print
prints
1, 4, 9, 16, 25
Lua
local squares = coroutine.wrap(function()
  local n = 1
  while true do coroutine.yield(n * n); n = n + 1 end
end)
local out = {}
for i = 1, 5 do out[i] = squares() end
print(table.concat(out, ", "))
prints
1, 4, 9, 16, 25

A coroutine you can go back to

This is where they part. A Lua coroutine is one live object: resuming it moves it on for everyone. A Sprout script is a value: resuming gives a new one and leaves the old one as it was. That is why a game can keep a script in its state and still rewind time.

Sprout
counter : script [| yield 1, yield 2, yield 3]
first : counter next
second : first next
second value print
-- first hasn't changed, so it can be resumed again
first next value print
prints
2
2
Lua
local counter = coroutine.create(function()
  coroutine.yield(1); coroutine.yield(2); coroutine.yield(3)
end)
coroutine.resume(counter)
local _, second = coroutine.resume(counter)
print(second)
-- there is only one counter, and it has moved on
local _, again = coroutine.resume(counter)
print(again)
prints
2
3

Your own operators

A Lua metatable gives a table its own +. In Sprout a record has a field named +, and left is the record it was sent to.

Sprout
vector : [
  + : [right | left with [x : left x + (right x), y : left y + (right y)]]
]
sum : (vector with [x : 1, y : 2]) + (vector with [x : 3, y : 4])
"[sum x], [sum y]" print
prints
4, 6
Lua
local Vector = {}
Vector.__index = Vector
function Vector.new(x, y) return setmetatable({x = x, y = y}, Vector) end
Vector.__add = function(a, b) return Vector.new(a.x + b.x, a.y + b.y) end
local sum = Vector.new(1, 2) + Vector.new(3, 4)
print(sum.x .. ", " .. sum.y)
prints
4, 6

Unpacking

Lua's multiple assignment unpacks values one by one. Sprout's patterns unpack lists, records and pairs, with ..rest for what's left (decision 101).

Sprout
[x, y] : 640x480
x * y print
[first, ..rest] : [1, 2, 3, 4]
rest print
prints
307200
[2, 3, 4]
Lua
local x, y = 640, 480
print(x * y)
local list = {1, 2, 3, 4}
local first, rest = list[1], {table.unpack(list, 2)}
print("[" .. table.concat(rest, ", ") .. "]")
prints
307200
[2, 3, 4]

A million random trials

Both estimate pi from a million random points. On this machine Sprout took 19 ms (Node, WebAssembly SIMD) and Lua 5.4 took 72 ms. Counting a million numbers took Sprout 4.3 ms and Lua 13 ms. LuaJIT, where it runs, would be faster than Lua 5.4; it wasn't measured here. Sprout's draws come from a seeded hash, so its answer is the same on every run.

Sprout
hit : [n | x : noise [n, 1], y : noise [n, 2], x * x + (y * y) < 1 [1] else [0]]
range 1000000 spork hit fold [0, [total h | total + h]] * 4 / 1000000 print
prints
3.141792
Lua
local hits = 0
for i = 1, 1000000 do
  local x, y = math.random(), math.random()
  if x * x + y * y < 1 then hits = hits + 1 end
end
print(hits * 4 / 1000000)
prints
3.14156
