Sprout and Rebol

Rebol showed that a language could be tiny, read left to right, write dates and money as they are, and parse anything with a dialect. Sprout takes all of that. Values written as they are

Rebol's best idea: a date, an amount of money or a size is written as it is, and knows its own maths. Sprout writes dates the ISO way, 2026-11-20, and keeps money in whole cents.

Sprout

$19.99 * 3 print
640x480 / 2 print
9:30 + 0:45 print
prints
2026-12-20
$59.97
320x240
10:15
Rebol
print 20-Nov-2026 + 30
print $19.99 * 3
print 640x480 / 2

Functions

Rebol's func takes a block of inputs and a block of code. A Sprout cell is both in one pair of brackets.

Sprout
twice : [n | n * 2]
twice 21 print
prints
42
Rebol
twice: func [n] [n * 2]
print twice 21

Parsing text

Rebol copies each piece into a variable. Sprout keeps them with as and gives back a record, so nothing outside the rule changes.

Sprout
"2026-11-20" parse [repeat [4, digit] as "year", "-", repeat [2, digit] as "month", "-", repeat [2, digit] as "day"] print
prints
[year : 2026, month : 11, day : 20]
Rebol
digit: charset "0123456789"
parse "2026-11-20" [copy year 4 digit "-" copy month 2 digit "-" copy day 2 digit]
print [year month day]

Finding every match

Rebol collects matches with an action in parens. Sprout has find-all.

Sprout
"call 555-1234 or 555-9876 today" find-all [repeat [3, digit], "-", repeat [4, digit]] print

[555-1234, 555-9876]

A grammar

Rebol words are looked up when the rule runs, so rules can refer to each other in any order. Sprout names are bound before use (decision 25), so the grammar is one cell that names itself, with its pieces as fields.

Sprout
expr : [
  factor : one-of [some digit, ["(", expr, ")"]]
  term : [factor, maybe-some [one-of "*/", factor]]
  term, maybe-some [one-of "+-", term]
]
["2*(3+4)", "2*(3+4", "1+2*3-4/5"] collect [t | t parse expr] print
prints
[true, false, true]
Rebol
digit: charset "0123456789"
expr: [term any [["+" | "-"] term]]
term: [factor any [["*" | "/"] factor]]
factor: [some digit | "(" expr ")"]
probe collect [foreach t ["2*(3+4)" "2*(3+4" "1+2*3-4/5"] [keep parse t expr]]
Rebol isn't installed here, so this side wasn't run.

A dialect

Rebol's is shorter: a block is already flat data. Sprout's quoted code keeps its phrases, so each command is checked as a whole with into.

Sprout
turtle : some one-of [into ['move, a-number], into ['turn, a-number]]
quote [move 10, turn 90, move 5] parse turtle print
prints
true
Rebol
turtle: [some ['move integer! | 'turn integer!]]
print parse [move 10 turn 90 move 5] turtle

Running a dialect

Rebol runs code in parens as the rule matches, and changes variables as it goes. Sprout folds over the program and gives back the new state, so nothing changes underneath.

Sprout
walk : [state [command, amount] |
  match [command, ['move, state with [x : state x + amount], 'turn, state with [heading : state heading + amount], any, state]]
]
quote [move 10, turn 90, move 5] fold [[x : 0, heading : 0], walk] print
prints
[x : 15, heading : 90]
Rebol
x: 0 heading: 0
parse [move 10 turn 90 move 5] [
  some ['move set n integer! (x: x + n) | 'turn set n integer! (heading: heading + n)]
]
print [x heading]

Code is data

Both treat code as data. Rebol blocks are data until you do them; Sprout needs quote, because its brackets are cells. Both can get a function's body back.

Sprout
program : quote [1 + 2, 3 * 4]
program print
eval program print
twice : [n | n * 2]
twice code print
prints
[1 + 2, 3 * 4]
12
[n | n * 2]
Rebol
program: [1 + 2 3 * 4]
probe program
print do program
twice: func [n] [n * 2]
probe body-of :twice

Records that don't change underneath you

Rebol makes a new object from an old one too, but any object can also be changed in place, for everyone who holds it. A Sprout record never changes, so a game can rewind.

Sprout
point : [x : 1, y : 2]
moved : point with [x : 5]
moved print
point print
prints
[x : 5, y : 2]
[x : 1, y : 2]
Rebol
point: make object! [x: 1 y: 2]
moved: make point [x: 5]
probe moved
point/x: 5    ; and an object can also be changed in place, for everyone holding it
probe point

Coroutines

Rebol has no coroutines. Sprout's script yields values and stays a value (decision 104).

Sprout
squares : script [| go : [n | yield (n * n), go (n + 1)], go 1]
squares take 5 print
prints
[1, 4, 9, 16, 25]
Rebol
; Rebol has no coroutines: a generator keeps its place in a variable
n: 0
next-square: does [n: n + 1 n * n]
probe collect [loop 5 [keep next-square]]

Unpacking

Rebol reads parts by path, size/x. Sprout can also unpack a pair or a date into names at once (decision 101).

Sprout
[w, h] : 640x480
w * h print
[y, m, d] : 2026-11-20
"[d]/[m]/[y]" print
prints
307200
20/11/2026
Rebol
size: 640x480
print size/x * size/y
day: 20-Nov-2026
print rejoin [day/day "/" day/month "/" day/year]
