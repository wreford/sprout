Sprout

Sprout is a small language for games and simulations. It runs in your browser, on a phone as well as a desk, and you can change a program while it runs.

Open the editor →

A taste

-- a cell: inputs | body
double : [n | n * 2]
[3, 1, 4] collect double print
-- prints [6, 2, 8]

-- math reads left to right
2 + 3 * 4 print
-- prints 20

-- with makes a new record
p : [x : 1, y : 2]
p with [x : 5] print
-- prints [x : 5, y : 2]

And the brain of every turret in Swarm, which you can change while they fire:

turret-program : [t |
  want : t dy atan2 (t dx)
  off : wrap (want - (t aim))
  [turn : clamp [off * 6, -1, 1], fire : (t far < reach) and (t cool <= 0) and (off abs < 0.06)]
]

Ideas

  • Everything is a cell. A function, a block, a list and a record are all written with square brackets.
  • One rule for order: left to right. There is no precedence table to learn.
  • No keywords for control. else, times, match and cond are ordinary cells in the library.
  • Values never change in place, so a running game can be rewound, saved or compared at any moment.
  • A game is three cells: start, update and draw.
  • Pure loops are compiled ahead. Loops over records of numbers are fused into one pass over columns, spork runs a million Monte Carlo trials on WebAssembly SIMD or the GPU, and WebGPU draws thousands of shapes in one call.
  • Games can be 3D: view, block, model and hold draw a scene with three.js and real CC0 models, from the same draw cell.
  • Two players, no server: send an invite by text, and two phones play in lockstep, peer to peer.
  • Game logic you can rewrite mid-game: the turrets in Swarm and SilverEye run a turret-program cell you edit while they fire.
  • Dates, times, money, sizes and colours are written as they are: 2026-11-20 + 30, $19.99 * 3, 640x480 / 2.
  • parse reads text and code with rules that are ordinary values, and a grammar is one cell.
  • Code is data: quote it, change it, eval it.
  • Scripts are coroutines that stay values, so a game can rewind through them.
  • Popular JavaScript libraries are wrapped as Sprout modules: chroma, simplex noise, math.js, date-fns, Fuse, compromise, Tone and Turf.
  • The editor is made for touch: a big code area, live values beside each line, drag a number to tweak it, and history to scrub back through.
  • The core is about a thousand lines of JavaScript. The standard words, parse and speed live in libraries.
