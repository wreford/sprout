Sprout

The standard library: 10 modules, 95 words, written in Sprout.

Each module is a cell whose fields are its words, there in every program: ease out-cubic 0.5, stats median xs, grid path [g, start, goal, open]. The source is in lib/, one file a module, and is worth reading: every word is a few lines. Every example below was run, and the comment under it is what it gave.

csv ease format grid json palette seeded shape stats vec

Built into every value as well: the list, record, text and number words, endless lists, the literals, parse, quote and script. They are in the spec (decisions 99 to 104).

csv

Tables in text, one row a line and commas between the values. The first line names the columns. Values that look like numbers become numbers. (Quoted values with commas inside aren't handled.)

csv cell-value [t]

one value from text: a number if it looks like one

csv read [csv-text]

the rows as records, named by the first line

csv read "name,age\nAda,36\nAlan,41"
-- [[name : Ada, age : 36], [name : Alan, age : 41]]
csv write [records]

records as text, a line per record, with the first record's fields as the columns

csv write [[name : "Ada", age : 36], [name : "Alan", age : 41]]
-- name,age
-- Ada,36
-- Alan,41

ease

Easing curves for animation. Each takes t, from 0 to 1, and gives a value that starts at 0 and ends at 1. Use one to move something smoothly: x : ease out-cubic (ease progress [elapsed, 2]) * 300

ease linear [t]

straight along, at one speed

ease linear 0.25
-- 0.25
ease in-quad [t]

starts slow, speeds up

ease in-quad 0.5
-- 0.25
ease out-quad [t]

starts fast, slows down

ease out-quad 0.5
-- 0.75
ease in-out-quad [t]

slow at both ends

ease in-out-quad 0.25
-- 0.125
ease in-cubic [t]

starts slower still

ease in-cubic 0.5
-- 0.125
ease out-cubic [t]

arrives gently: the usual choice for things that slide into place

ease out-cubic 0.5
-- 0.875
ease in-out-cubic [t]

slow at both ends, more so than in-out-quad

ease in-out-cubic 0.75
-- 0.9375
ease out-back [t]

goes a little past the end, then settles back

ease out-back 0.8
-- 1.04645056
ease out-elastic [t]

springs past the end and wobbles to a stop

ease out-elastic 0.3
-- 0.875
ease out-bounce [t]

bounces like a dropped ball

ease out-bounce 0.9
-- 0.988125
ease smooth [t]

a soft S-curve, slow at both ends

ease smooth 0.25
-- 0.15625
ease progress [elapsed, seconds]

how far through something is, from 0 to 1: elapsed seconds out of the whole

ease progress [1.5, 2]
-- 0.75
ease ping-pong [t]

t from 0 to 1 and back again, for things that go to and fro

ease ping-pong 1.25
-- 0.75
ease between [curve, from, to, t]

a curve applied between two values: [curve, from, to, t]

ease between [ease out-cubic, 0, 300, 0.5]
-- 262.5

format

Numbers and text made ready to show.

format commas [n]

a whole number with commas between the thousands

format commas 1234567
-- 1,234,567
format places [n, count]

a number with a fixed number of places after the point

format places [3.14159, 2]
-- 3.14
format percent [x]

a share from 0 to 1 as a percent

format percent 0.256
-- 26%
format ordinal [n]

1st, 2nd, 3rd, 4th ... 11th, 12th, 13th, 21st

format ordinal 22
-- 22nd
format plural [n, word]

a count and a word, with an s when there isn't exactly one

format plural [3, "apple"]
-- 3 apples
format clock [seconds]

seconds as m:ss, or h:mm:ss past an hour

format clock 3725
-- 1:02:05
format wrap [words-text, width]

text broken into lines no longer than width, at spaces

format wrap ["the quick brown fox jumps over the lazy dog", 12]
-- [the quick, brown fox, jumps over, the lazy dog]
format centre [line, width]

text in the middle of a line width wide

format centre ["hi", 6]
--   hi
format title [line]

Every Word Capitalized

format title "the sprout standard library"
-- The Sprout Standard Library
format bar [value, most, width]

a bar of blocks, value out of most, width wide

format bar [3, 4, 8]
-- ######..

grid

A grid is a list of rows, each a list of cells, counted from 1 like every Sprout list. Read and change cells by x (across) and y (down), find neighbours, flood-fill and find the shortest way through.

grid make [width, height, value]

a grid width by height with every cell the same

grid make [3, 2, 0]
-- [[0, 0, 0], [0, 0, 0]]
grid size [g]

how wide and how tall, as a pair

grid size (grid make [3, 2, 0])
-- 3x2
grid inside [g, x, y]

is x, y on the grid?

grid inside [grid make [3, 2, 0], 3, 3]
-- false
grid at [g, x, y]

the cell at x, y (false off the grid)

grid at [[[1, 2], [3, 4]], 2, 1]
-- 2
grid put [g, x, y, value]

a new grid with the cell at x, y changed

grid put [grid make [3, 2, 0], 2, 1, 9]
-- [[0, 9, 0], [0, 0, 0]]
grid beside [g, x, y]

the four cells beside x, y (up, right, down, left) that are on the grid, as [x, y]

grid beside [grid make [3, 3, 0], 1, 1]
-- [[2, 1], [1, 2]]
grid around [g, x, y]

the eight cells round x, y that are on the grid, as [x, y]

grid around [grid make [3, 3, 0], 1, 1] length
-- 3
grid count-around [g, x, y, value]

how many of the eight cells round x, y hold value (for Life and minesweeper)

grid count-around [[[1, 1, 0], [0, 0, 0], [0, 1, 1]], 2, 2, 1]
-- 4
grid cells [g]

every cell with where it is: a list of [x, y, value]

grid cells [[1, 2], [3, 4]]
-- [[1, 1, 1], [2, 1, 2], [1, 2, 3], [2, 2, 4]]
grid map [g, change]

a new grid made by a cell given [x, y, value] for every cell

grid map [[[1, 2], [3, 4]], [[x, y, v] | v * 10]]
-- [[10, 20], [30, 40]]
grid region [g, x, y]

the cells joined from x, y through cells of the same value, as [x, y]

grid region [[[1, 1, 0], [0, 1, 0], [0, 1, 1]], 1, 1] length
-- 5
grid fill [g, x, y, value]

a new grid with the region at x, y changed to value

grid fill [[[1, 1, 0], [0, 1, 0]], 1, 1, 7]
-- [[7, 7, 0], [0, 7, 0]]
grid path [g, start, goal, open]

the shortest way from one cell to another, stepping only on cells that pass the test, as a list of [x, y] (false if there is no way)

grid path [[[0, 0, 0], [1, 1, 0], [0, 0, 0]], [1, 1], [1, 3], [v | v = 0]]
-- [[1, 1], [2, 1], [3, 1], [3, 2], [3, 3], [2, 3], [1, 3]]
grid show [g]

the grid as lines of text, one per row

grid show [[1, 2], [3, 4]]
-- 1 2
-- 3 4

json

JSON text read into records and lists, and written back. null reads as false; dates, money and other kinds are written as their text.

json read

records and lists from JSON text (put \[ for a [ inside Sprout text)

json read "{\"a\": 1, \"b\": \[true, null]}"
-- [a : 1, b : [true, false]]
json write

a value as JSON text

json write [name : "Ada", due : 2026-11-20, tags : ["x"]]
-- {"name":"Ada","due":"2026-11-20","tags":["x"]}
json pretty

the same, set out on several lines

json pretty [a : 1]
-- {
--   "a": 1
-- }

palette

Colours made from hue, saturation and lightness, colours mixed along a line, and a few sets that go together.

palette hsl [hue, sat, light]

a colour from hue (0 to 360), saturation and lightness (0 to 1)

palette hsl [30, 0.8, 0.55]
-- #e88c30
palette along [stops, t]

a colour part of the way along a list of colours: t of 0 is the first, 1 the last

palette along [[#000000, #ff0000, #ffffff], 0.75]
-- #ff8080
palette wheel [n, sat, light]

n colours evenly round the colour wheel

palette wheel [4, 0.7, 0.5]
-- [#d92626, #80d926, #26d9d9, #8026d9]
palette grey [level]

a grey from 0 (black) to 1 (white)

palette grey 0.5
-- #808080
palette warm

warm colours, for fire and sunsets

palette warm length
-- 5
palette cool

cool colours, for water and night

palette cool @ 3
-- #1f6f8b
palette soft

soft colours that sit well together

palette soft @ 1
-- #f4b6c2

seeded

Random choices you can repeat. Each one takes a seed (any number): the same seed always gives the same answer, on every machine, and a game that rewinds gets the same luck back. Use a different seed for each choice, such as the frame number, or a thing's number times 10 plus which choice it is.

seeded number [seed]

a number from 0 up to 1

seeded number 42
-- 0.0565482103
seeded between [low, high, seed]

a number from low up to high

seeded between [10, 20, 42]
-- 10.5654821033
seeded whole [low, high, seed]

a whole number from low to high, both included

seeded whole [1, 6, 42]
-- 1
seeded chance [p, seed]

true with chance p (from 0 to 1)

seeded chance [0.5, 42]
-- false
seeded pick [items, seed]

one item of a list

seeded pick [["rock", "paper", "scissors"], 42]
-- rock
seeded shuffle [items, seed]

the list in a shuffled order

seeded shuffle [[1, 2, 3, 4, 5], 42]
-- [2, 3, 5, 4, 1]
seeded bell [mean, spread, seed]

a number from a bell curve: usually near mean, spread out by spread

seeded bell [100, 15, 42] round
-- 99
seeded in-circle [r, seed]

a point inside a circle of radius r round 0x0, spread evenly

seeded in-circle [10, 42] x round
-- -2
seeded weighted [items, weights, seed]

n choices from a list, by their weights: [items, weights, seed]

seeded weighted [["common", "rare"], [9, 1], 42]
-- common

shape

The points of shapes, as lists of pairs, ready to draw or test. Nothing here draws: draw a shape's edges with line, as in shape edges (shape polygon [180x240, 50, 6]) each [[a, b] | line [a x, a y, b x, b y, "#fff"]]

shape circle [c, r, n]

n points evenly round a circle at centre c (a pair) with radius r

shape circle [0x0, 10, 4] collect [p | p x round]
-- [10, 0, -10, 0]
shape polygon [c, r, sides]

a regular polygon with n sides, its first corner straight up

shape polygon [0x0, 10, 3] length
-- 3
shape star [c, outer, inner, n]

a star with n points, between radius outer and inner

shape star [0x0, 10, 5, 5] length
-- 10
shape box [corner, size]

the four corners of a box from its top-left corner and its size (both pairs)

shape box [0x0, 4x2]
-- [0x0, 4x0, 4x2, 0x2]
shape edges [points]

the sides of a closed shape: each point with the next, the last with the first, as [a, b]

shape edges [0x0, 1x0, 0x1] length
-- 3
shape move [points, by]

the shape moved by a pair

shape move [[0x0, 1x1], 5x5]
-- [5x5, 6x6]
shape turn [points, c, angle]

the shape turned round centre c by an angle in radians

shape turn [[1x0], 0x0, 3.141592653589793] collect [p | p x round]
-- [-1]
shape grow [points, c, times-bigger]

the shape grown or shrunk round centre c

shape grow [[2x2], 1x1, 3]
-- [4x4]
shape area [points]

the area inside a closed shape

shape area (shape box [0x0, 4x2])
-- 8
shape centre [points]

the middle of the points

shape centre (shape box [0x0, 4x2])
-- 2x1
shape bounds [points]

the smallest box round the points, as [top-left, bottom-right]

shape bounds [3x1, 0x4, 2x2]
-- [0x1, 3x4]
shape holds [points, p]

is point p inside the closed shape?

shape holds [shape box [0x0, 4x2], 1x1]
-- true

stats

Numbers that sum up a list of numbers.

stats mean [xs]

the average

stats mean [2, 4, 9]
-- 5
stats median [xs]

the middle value once they are sorted (the average of the two middle ones for an even count)

stats median [7, 1, 3, 9]
-- 5
stats mode [xs]

the value that comes up most often (the first of them, if several tie)

stats mode [3, 1, 3, 2, 1, 3]
-- 3
stats variance [xs]

how spread out the values are: the mean of the squared distances from the mean

stats variance [2, 4, 4, 4, 5, 5, 7, 9]
-- 4
stats spread [xs]

the standard deviation: the square root of the variance

stats spread [2, 4, 4, 4, 5, 5, 7, 9]
-- 2
stats percentile [xs, p]

the value below which a share p of them fall, from 0 to 1 (between two values, part of the way)

stats percentile [[15, 20, 35, 40, 50], 0.4]
-- 29
stats range-of [xs]

the smallest and largest, as a pair

stats range-of [4, 9, 1]
-- 1x9
stats normalize [xs]

each value placed between 0 (the smallest) and 1 (the largest)

stats normalize [10, 15, 20]
-- [0, 0.5, 1]
stats histogram [xs, n]

how many values fall in each of n equal steps from the smallest to the largest

stats histogram [[1, 2, 2, 3, 3, 3, 4], 3]
-- [1, 2, 4]
stats correlation [xs, ys]

how closely two lists rise and fall together, from -1 to 1

stats correlation [[1, 2, 3, 4], [2, 4, 5, 8]]
-- 0.981155781
stats summary [xs]

a record of the usual numbers for a list

stats summary [3, 1, 4, 1, 5, 9, 2, 6]
-- [n : 8, mean : 3.875, median : 3.5, spread : 2.571, smallest : 1, largest : 9]

vec

Two-dimensional vectors, written as pairs like 3x4. Pairs already add, take away, multiply and divide. These are the other things a game needs: length, direction, angle, rotation.

vec of [x, y]

a vector from two numbers

vec of [3, 4]
-- 3x4
vec from-angle [angle]

a vector one long, pointing at an angle (in radians)

vec from-angle 0
-- 1x0
vec size [v]

how long a vector is

vec size 3x4
-- 5
vec unit [v]

the same direction, one long

vec unit 3x4
-- 0.6x0.8
vec angle [v]

the angle a vector points at, in radians

vec angle 0x1
-- 1.5707963268
vec rotate [v, turn]

turned round by an angle, in radians

vec rotate [1x0, 1.5707963267948966]
-- 0x1
vec dot [a, b]

how much two vectors point the same way

vec dot [1x0, 0x1]
-- 0
vec distance [a, b]

the distance between two points

vec distance [0x0, 3x4]
-- 5
vec mix [a, b, t]

part of the way from a to b: t of 0 is a, 1 is b

vec mix [0x0, 10x20, 0.5]
-- 5x10
vec limit [v, most]

no longer than most, in the same direction

vec limit [30x40, 5]
-- 3x4
vec reflect [v, n]

bounced off a surface facing the way of n (n one long)

vec reflect [1x-1, 0x1]
-- 1x1
vec perpendicular [v]

turned a quarter to the left

vec perpendicular 1x0
-- 0x1
