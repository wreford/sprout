Sprout

The standard library: 54 modules, 511 words, written in Sprout. And 1 kit that draw, and 9 wrapped libraries.

Each module is a cell whose fields are its words, there in every program: ease out-cubic 0.5, stats median xs, grid path [g, from, to, open]. The source is in lib/, one file a module, and is worth reading: every word is a few lines.

One way of working runs through all of them. A point, a size, a cell of a grid and a hex are pairs, like 3x4, read with p x and p y, and added and scaled like numbers. A word's inputs come in the same order: what it works on, then how, then the time or the seed. Randomness only ever comes from a seed, through seeded, so a game that rewinds, and a second phone playing along, get the same luck. And every example below shows its answer, which is worked out, and checked, each time the library is built.
