Stop Typing Percent Complete

On most status reports, percent complete is a number somebody types. It creeps up a few points a week, because nobody wants the argument, then parks at 95 for three months.

Let the records set it. A wall is done when the inspection is signed, the deficiencies are closed and the test record is filed. A system is done when all its walls, pipes and panels are. Nobody gets to type a number.

  • The argument changes. "It's basically done" turns into "which signature is missing?"
  • Partial progress becomes a count: evidence on file against evidence required.
  • Closeout shows up in month three instead of month thirty, as missing paperwork on work everyone called finished.
  • Rollups stop lying. A floor is done when its rooms are (one breakdown).

Expect the first report built this way to show less progress than last week's typed one. That gap was always there.
