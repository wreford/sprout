Green Should Cost a Name

trust field

Anyone can turn a cell green. It costs nothing, so it drifts optimistic — a green report is often just a report nobody wanted to argue about.

A hold point works differently: someone signs, and the signature follows them. The weld is good because a person with a stamp says so.

So maybe every green should work like a hold point — status claims signed by someone whose name rides on them. There would be fewer greens. The ones left might mean something.
