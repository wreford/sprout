Programmable Procedures

software theory

A procedure in a PDF is advice. What crews actually run is a program — steps, conditions, hold points, quals — with people as the runtime.

Diff a procedure · not a binder

Write the procedure as atoms and every execution instantiates trackable constraints: versioned, diffable, auditable. Change the procedure and every future run changes with it. Try that with a binder.
