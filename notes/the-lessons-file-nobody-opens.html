The Lessons File Nobody Opens

Every job ends with a lessons-learned report. It goes into the closeout binder, and the next team never opens it. They're busy, it's forty pages, and half the lessons are "communicate better".

A lesson is learned when it changes what the next job does by default: a line in the estimate checklist, a hold point in the procedure, a row in the startup schedule template.

So end every lessons session by asking which document changes, and who changes it this week. If no document changes, nothing was learned. It was just remembered for a while.
