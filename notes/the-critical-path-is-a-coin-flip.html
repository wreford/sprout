The Critical Path Is a Coin Flip

scheduling metrics

The critical path gets presented as a fact. Run the same schedule through a thousand simulated weathers and deliveries and a different path goes critical in a lot of the runs.

Worse, the red line moves every update — so management whipsaws crews toward whatever went red this month. The percentage is steadier: an activity critical in sixty of a hundred futures deserves attention every month, whichever path this month's printout crowned.

Critical, most mornings

Float answers a question about one run. Criticality answers a question about the job. I want it as a column in the layout; still arguing for it.
