The Critical Path Is a Coin Flip

scheduling metrics

The critical path gets presented as a fact. Run the same schedule through a thousand simulated weathers and deliveries and a different path goes critical in a lot of the runs.

So criticality is a probability, and every activity has one. The single red line is one draw from that distribution.

I'd rather see an activity's criticality percentage than its float. Float reports what one run claims; the percentage says how often the activity actually decides the job. Untested at scale, noted.
